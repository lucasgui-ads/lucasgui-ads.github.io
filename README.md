# Materiais do @lucastadeu357

Páginas dos materiais que vão no direct pela automação de comentário (skill `automacao-direct` do cérebro). Publicado no GitHub Pages.

## Material novo

1. Copie a pasta `_modelo/` com o nome do material, curto e sem acento (ex.: `prompt-fotos/`).
2. Troque tudo que está entre `{{ }}` no `index.html` dela.
3. Publique (commit e push). O endereço fica `https://lucasgui-ads.github.io/{pasta}/`.
4. Esse endereço é o botão do direct na automação.

## Regras

- Todas as páginas têm `noindex`: só chega quem recebeu o link.
- Nunca citar as empresas do Lucas (regra 11 do cérebro).
- O bloco de oferta fica comentado até ter produto.
- O repositório é público: não guardar aqui nada que não possa ser visto.
